# Changelog

## 0.9.0-beta (2026-11-05)
First beta. Everything is built and tested offline; nothing has been tested in game yet.

- Guild change log: joins/rejoins (inviter, times before, time away), leaves vs. kicks (and kicker),
  promotions/demotions (and by whom), level-ups (with filters), note changes, renames, rank renames,
  back from inactivity, kick recommendations, banned-player warnings, guild renames.
  Back-fills from the guild event log, including changes made while you were offline.
- Member card on guild roster mouseover (click to pin), plus "Member card" in right-click menus.
- Roster, Audit (with the join date tool), Bans, Tools (kick/promote/demote/alt ranks via one secure
  button per member), Events, Sync and Export tabs.
- Alt/main groups with the main's name shown after alts in chat.
- Sync of join/promotion dates, alts, custom notes, birthdays and bans, with rank limits and
  guild-wide settings from the guild master.
- Group info: guildies, former guildies and banned players in your group; trade-range dots.
- `!note` public-note requests, join date written into notes, restore points, export for spreadsheets.
- `/gmru probe` diagnostics for bug reports.
- Name suggestions while typing when adding an alt or banning by name.
- Names are kept as the game gives them (no realm guessing), fixing invites and sync echo.
